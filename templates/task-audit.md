# Task audit template

Find the five agency tasks worth automating first, then measure the hours you save.

## Step 1: Log tasks for one week

Everyone on the team keeps this table open for five working days. Add a row each time you do a task that you have done before.

| Date | Person | Client | Task | Stage | Minutes | Tool(s) used |
|---|---|---|---|---|---|---|
| | | | | | | |

Stage is one of: onboarding, creative, launch, reporting, client comms, admin.

Do not skip the small ones. Five-minute tasks done 40 times a week are the best candidates.

## Step 2: Group and total

Group rows that are the same task. For each group, fill in:

| Task | Times per week | Avg minutes | Minutes per month |
|---|---|---|---|
| | | | = times per week x avg minutes x 4 |

## Step 3: Score each task

Give each task 1 point per "yes".

| Test | Task A | Task B | Task C |
|---|---|---|---|
| Happens at least weekly | | | |
| You can write the steps down | | | |
| Inputs are in a tool or file the AI can reach | | | |
| You can judge the output in 30 seconds | | | |
| Mistakes are cheap to fix before a client sees it | | | |
| Minutes per month is over 120 | | | |

Pick the 5 tasks with the highest scores. Break ties by minutes per month.

## Step 4: Decide the gate for each

| Task | Client-facing? | Spends money? | Approver | Gate |
|---|---|---|---|---|
| | | | | |

If either column is yes, the AI saves a draft and the approver sends or applies it.

## Step 5: Record the baseline

| Task | Baseline minutes per run | Runs per month |
|---|---|---|
| | | |

Use the average from your log, not a guess.

## Step 6: After you automate, measure again

Run the skill for four weeks. Each run, log your own review and edit time (not the AI's run time).

| Task | New minutes per run | Runs per month | Hours saved per month |
|---|---|---|---|
| | | | = (baseline - new) x runs / 60 |

## Step 7: Decide what next

- Saved over 5 hours a month and edits are few: schedule it and move on.
- Saved little: read your edits. Add them to the skill, or the task needs more human judgment than you thought.
- Edits are heavy: the SOP was unclear. Rewrite the steps, then retest.

Then repeat the audit with the next five tasks. Keep the log. After a quarter you will have your own numbers for what AI saves your agency.
